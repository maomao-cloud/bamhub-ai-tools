# manage-skills 统一管理入口

已确认：默认交互入口先选择“管理当前环境的 skills”或“拉取上游 skills”。显式 status、plan、apply、recover 保持原行为。

管理分支复用已有 catalog、目标选择、已挂载回显及确认流程。上游分支从脚本所在仓库的 skills/sources.json 读取来源，多选后逐来源 check，展示完整状态、提交号与文件变化，确认后仅 apply update-available 来源。默认不 force，不自动提交、推送或更改挂载；错误按来源展示并继续。取消不 apply，无更新不确认。

上游同步固定作用于工具所在仓库，不将 --catalog 当成同步写入目标。不执行本仓库 git pull。交互入口拒绝与挂载专属参数组合进行上游同步，避免静默忽略参数。

复用现有同步器，新增薄适配模块。同步不是无副作用读取：check 可能访问网络和临时 checkout，apply 会替换受管目录；提示用户既有挂载的源内容可能随更新改变，但不重新管理软链接或 manifest。

测试覆盖分支隔离、取消、无更新、来源部分失败、dirty 拒绝和 CLI 挂载兼容性。无需新增依赖或修改上游镜像。

入口为单选，默认高亮第一项，方向键移动、Enter 确认，无需空格。所有 TTY 菜单局部重绘，不全屏清除；完成后保留摘要，长列表窗口化并截断超宽显示，退出恢复终端状态。
